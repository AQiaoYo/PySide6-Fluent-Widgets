# Dialog Box 示例

对应 `qfluentwidgets.components.dialog_box` 子包，包含对话框组件。

## 组件列表

- [color_dialog](color_dialog/) - 颜色对话框
- [custom_message_box](custom_message_box/) - 自定义消息框
- [dialog](dialog/) - 基础对话框
- [folder_list_dialog](folder_list_dialog/) - 文件夹列表对话框
- [message_dialog](message_dialog/) - 消息对话框

## 运行方式

```bash
python examples/dialog_box/<组件名>/demo.py
```
