# Material 示例

对应 `qfluentwidgets.components.material` 子包，包含亚克力材质效果组件。

## 组件列表

- [acrylic_brush](acrylic_brush/) - 亚克力笔刷
- [acrylic_combo_box](acrylic_combo_box/) - 亚克力下拉框
- [acrylic_flyout](acrylic_flyout/) - 亚克力浮出层
- [acrylic_label](acrylic_label/) - 亚克力标签
- [acrylic_line_edit](acrylic_line_edit/) - 亚克力文本输入框
- [acrylic_menu](acrylic_menu/) - 亚克力菜单
- [acrylic_tool_tip](acrylic_tool_tip/) - 亚克力工具提示
- [acrylic_widget_menu](acrylic_widget_menu/) - 亚克力部件菜单

## 运行方式

```bash
python examples/material/<组件名>/demo.py
```
