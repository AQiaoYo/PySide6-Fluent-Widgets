# Navigation 示例

对应 `qfluentwidgets.components.navigation` 子包，包含导航组件和窗口。

## 组件列表

### 导航控件
- [breadcrumb_bar](breadcrumb_bar/) - 面包屑导航
- [navigation_bar](navigation_bar/) - 导航栏
- [navigation_header](navigation_header/) - 导航头部
- [navigation_user_card](navigation_user_card/) - 导航用户卡片
- [pivot](pivot/) - 枢轴导航
- [segmented_widget](segmented_widget/) - 分段控件
- [segmented_tool_widget](segmented_tool_widget/) - 分段工具控件
- [stacked_widget](stacked_widget/) - 堆叠控件
- [tab_view](tab_view/) - 标签页视图
- [tab_widget](tab_widget/) - 标签页部件

### 导航窗口
- [fluent_window](fluent_window/) - Fluent 风格主窗口
- [ms_fluent_window](ms_fluent_window/) - Microsoft Fluent 风格窗口
- [split_fluent_window](split_fluent_window/) - 分割式 Fluent 窗口

### 导航模式示例
- [navigation_stack](navigation_stack/) - 堆栈式导航（原 navigation1）
- [navigation_pivot](navigation_pivot/) - 枢轴式导航（原 navigation2）
- [navigation_segmented](navigation_segmented/) - 分段式导航（原 navigation3）

## 运行方式

```bash
python examples/navigation/<组件名>/demo.py
```
