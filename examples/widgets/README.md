# Widgets 示例

对应 `qfluentwidgets.components.widgets` 子包，包含基础 UI 组件。

## 组件列表

### 按钮
- [button](button/) - 各类按钮（PushButton、ToolButton、DropDownButton、SplitButton 等）
- [check_box](check_box/) - 复选框
- [radio_button](radio_button/) - 单选按钮
- [switch_button](switch_button/) - 开关按钮
- [command_bar](command_bar/) - 命令栏

### 输入控件
- [combo_box](combo_box/) - 下拉框
- [model_combo_box](model_combo_box/) - 模型下拉框
- [line_edit](line_edit/) - 文本输入框
- [slider](slider/) - 滑块
- [spin_box](spin_box/) - 数值输入框

### 日期时间
- [calendar_picker](calendar_picker/) - 日历选择器（已在 date_time/ 中，此处为快捷入口）

### 菜单
- [menu](menu/) - 菜单
- [widget_menu](widget_menu/) - 部件菜单
- [system_tray_menu](system_tray_menu/) - 系统托盘菜单

### 标签与显示
- [label](label/) - 标签（CaptionLabel、BodyLabel、TitleLabel 等）
- [font_icon](font_icon/) - 字体图标
- [image_label](image_label/) - 图像标签
- [fluent_widget](fluent_widget/) - Fluent 风格窗口组件

### 数据视图
- [list_view](list_view/) - 列表视图
- [table_view](table_view/) - 表格视图
- [tree_view](tree_view/) - 树形视图
- [tree_widget](tree_widget/) - 树形部件
- [flip_view](flip_view/) - 翻转视图
- [card_widget](card_widget/) - 卡片部件

### 进度与状态
- [progress_bar](progress_bar/) - 进度条
- [progress_ring](progress_ring/) - 进度环
- [info_badge](info_badge/) - 信息徽标
- [info_bar](info_bar/) - 信息栏
- [progress_info_bar](progress_info_bar/) - 带进度环的信息栏
- [state_tool_tip](state_tool_tip/) - 状态提示
- [tool_tip](tool_tip/) - 工具提示

### 滚动
- [scroll_area](scroll_area/) - 滚动区域
- [pips_pager](pips_pager/) - 分页指示器

### 媒体
- [avatar_widget](avatar_widget/) - 头像组件
- [media_player](media_player/) - 媒体播放器

### 浮出层
- [flyout](flyout/) - 浮出层
- [teaching_tip](teaching_tip/) - 教学提示

## 运行方式

```bash
python examples/widgets/<组件名>/demo.py
```
