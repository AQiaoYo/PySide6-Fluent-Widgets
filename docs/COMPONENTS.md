# 组件索引

本文档列出 PySide6-Fluent-Widgets 提供的所有组件及其对应示例。
点击组件名可直接跳转到对应的示例代码。

> **提示**：每个示例都是独立的 `demo.py`，可直接运行。
>
> ```bash
> python examples/widgets/button/demo.py
> ```

## 快速查找

按组件功能快速定位：

- **按钮类**：PushButton / ToolButton / DropDownButton / SplitButton / ToggleButton / HyperlinkButton / PillButton
- **输入类**：LineEdit / TextEdit / ComboBox / SpinBox / Slider
- **选择类**：CheckBox / RadioButton / SwitchButton
- **展示类**：Label / InfoBar / InfoBadge / ToolTip / TeachingTip / ProgressBar / ProgressRing
- **数据视图**：ListView / TableView / TreeView / FlipView
- **容器**：CardWidget / ScrollArea / StackedWidget
- **菜单**：RoundMenu / SystemTrayMenu
- **导航**：NavigationInterface / FluentWindow / Pivot / SegmentedWidget / TabView
- **对话框**：Dialog / MessageBox / ColorDialog / FolderListDialog
